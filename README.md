# DeskClock
A ideia deste projeto é fazer um relógio de mesa de escritório modulável que mostre, além das horas, mostre a temperatura ambiente, previsão do tempo e outras informações através de um display OLED. O esquema elétrico será montado de modo a tornar este projeto modulável para acrescentar mais componentes periféricos que agreguem ao todo. Além disso, o projeto também será uma plataforma de aprendizado para aprender mais sobre programação de embarcados, roteamento de sinais RF, seleção de componentes (custo-benefício) e por aí vai.
